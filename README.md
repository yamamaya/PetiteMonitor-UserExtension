# プチモニ ユーザー拡張サンプル

これは、プチモニのユーザー拡張のサンプルコードです。

## 使い方

1. このレポジトリをクローンして、Visual Studioで開いてください。
1. プチモニを起動してタスクトレイのアイコンを右クリックし、「設定」を開いて「ユーザー拡張」をONにしてください。
1. プチモニのコントロールパネルのLEDの設定で「ユーザー拡張デジタル１」を選択してください。
1. このサンプルを実行すると、プチモニのLEDが点滅します。

## 内容

- **PetiteMonitor-UserExtension_CS**:<br />C#で書かれたサンプルです。
- **PetiteMonitor-UserExtension_CPP**:<br />C++で書かれたサンプルです。
- **PetiteMonitor-UserExtension_Py**:<br />Pythonで書かれたサンプルです。
